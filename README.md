# 拍照解方塊

用手機拍下魔術方塊的 6 面，網頁會自動辨色、算出還原步驟，再一步一步帶你轉。

**線上使用：** https://dq042000.github.io/cube-solver/

不用安裝 App，手機瀏覽器打開就能用，舊手機也可以。

## 怎麼用

1. 用手機打開上面的網址。
2. 照畫面指示依序拍 6 面：正、右、背、左、頂、底。
3. 每拍一張，拖曳九宮格對準方塊，按「這面好了」。
4. 6 面拍完後看展開圖，顏色認錯的格子點一下就會換色。
5. 按「算出解法」，照著畫面一步一步轉。

沒有方塊也能先按「用範例試玩」看看效果。

## 拿法

拿法固定如下，拍照和轉的過程都要保持：

| 位置 | 中心顏色 |
|------|----------|
| 上 | 黃 |
| 前 | 紅 |
| 右 | 綠 |
| 左 | 藍 |
| 後 | 橘 |
| 下 | 白 |

## 符號

| 符號 | 意思 |
|------|------|
| `U` `D` `F` `B` `L` `R` | 頂、底、正面、背面、左、右那一層 |
| 只有字母，例如 `R` | 對著那一面看，順時針轉 90° |
| 加撇號，例如 `R'` | 逆時針轉 90° |
| 加 2，例如 `R2` | 轉 180° |

## 技術說明

- 整個程式只有一個檔案：`index.html`，不用 build。
- 解題用 [cubejs](https://github.com/ldez/cubejs)（Kociemba two-phase 演算法），從 jsDelivr CDN 載入。
- 先給 22 步以內的解法，再在背景的 Web Worker 找更短的，通常約 20 步。不保證是理論上最少步數。
- 辨色：每格取中間區域的顏色中位數，轉成 Lab 色彩空間後，以各面中心格為基準分色，並限制每色剛好 9 格。
- 算之前會檢查方塊狀態是否可能存在（角塊扭轉、邊塊翻轉、奇偶性），不可能的狀態會提示哪裡有問題。

## 本機開發

直接用瀏覽器打開 `index.html` 即可。

推到 `main` 分支後，GitHub Pages 約 1 分鐘內會更新線上版本。
